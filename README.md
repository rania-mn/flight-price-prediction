# Flight Price Prediction

A machine learning project that predicts the price of a flight in India from its characteristics (airline, route, time, stops, class, duration, days left before departure).

It includes data exploration and preprocessing, a comparison of several regression models, and the deployment of the best one as an API (FastAPI) and a small web app (Flask).

## Project structure

- `notebooks/`: data exploration, preprocessing and model training
- `app/`: prediction API and web app
